# 此生生命表

一个人生模拟网页游戏：按真实的出生统计随机投胎到 195 个国家/地区之一，在过去（1900–2025）、现在或未来（2027–2100）的世界里过完一生。

**在线玩：** https://mingxintan-coder.github.io/life-table/

## 玩法
- 每一年按年龄、年代、国家、城乡和家境发生多件事，在升学、工作、恋爱、婚育、移民、治疗、理财、保险的岔路口做选择。
- 死亡按各国分性别、分年份的生命表随机发生；精算页显示你的 qₓ、风险乘数、余命、存活曲线，可以投保定期寿险、医疗险和终身年金。
- 同一秒出生的另外四个人和你并排活到最后。
- 夭折、疾病、战争、饥荒、贫困、成瘾、家暴、性暴力、自杀等沉重内容按真实统计发生，不描写场面，并附求助渠道。适合 15 岁以上。
- 追思馆、人生分享和前世记录保存在你自己的浏览器里。

## 数据来源
Gapminder（汇总联合国《世界人口展望》、世界银行、IHME 等）、Gapminder Systema Globalis、World Happiness Report、UCDP（经 Our World in Data）、IHME 自杀率。部分指标为估算，详见页面底部“哪些是真实数据”。

单个 `index.html`，无需构建，直接打开即可。
